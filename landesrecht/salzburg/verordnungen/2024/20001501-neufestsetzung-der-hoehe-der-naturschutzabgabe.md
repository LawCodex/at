# Neufestsetzung der Höhe der Naturschutzabgabe

Verordnung der Salzburger Landesregierung vom 14. Oktober 2024 zur Neufestsetzung der Höhe der Naturschutzabgabe

StF: LGBl Nr 86/2024

## Präambel/Promulgationsklausel

Auf Grund des § 59 Abs 3 des Salzburger Naturschutzgesetzes 1999 – NSchG, LGBl Nr 73/1999, in der geltenden Fassung wird verordnet:

## § 1

Die Höhe der Naturschutzabgabe wird wie folgt neu festgesetzt:

| Lockergesteine¹) |  | 23,40 Cent/t |
|---|---|---|
| Festgesteine²). |  | 23,40 Cent/t |
| Torf |  | 46,80 Cent/m<sup>3</sup> |
|  |  |  |

¹) zB Schotter, Sande, Kiese

²) zB Kalksteine, Marmor, Dolomite, Tone, Mergel, Konglomerate, Diabas, Quarzite, Gips, Anhydrit, Gneise, Erze, mineralische Erden

## § 2

(1) Diese Verordnung tritt mit 1. Jänner 2025 in Kraft.

(2) Auf die Entrichtung der Naturschutzabgabe für das Jahr 2024 sind die bisher geltenden Abgabensätze anzuwenden.
