# Bezügereform-Begleitgesetz

Gesetz vom 23. Oktober 1997, mit dem das Salzburger Landes-Verfassungsgesetz 1945, das Salzburger Bezügegesetz 1992, das Salzburger Landesrechnungshofgesetz 1993, das Salzburger Schulaufsichts-Ausführungsgesetz 1995, das Salzburger Stadtrecht 1966, des Gemeindeorgane-Bezügegesetz, das Kollegialorgane-Sitzungsentschädigungsgesetz, das Salzburger Landesbeamtengesetz 1987, das Salzburger Landesvertragsbedienstetengesetz 1987, das Salzburger Magistratsbeamtengesetz 1981, das Salzburger Gemeindebeamtengesetz 1968 und das Salzburger Gemeindevertragsbedienstetengesetz 1968 im Zusammenhang mit der Neuregelung der für die Ausübung bestimmter Funktionen gebührenden Bezüge geändert werden (Bezügereform-Begleitgesetz)

StF: [LGBl Nr 5/1998](https://alex.onb.ac.at/cgi-content/alex?aid=lgs&datum=1998&page=31&size=45) (Blg LT 11. GP: [IA 580](https://service.salzburg.gv.at/lpi/viewExtern?id=12038), 4. Sess [AB 75](https://service.salzburg.gv.at/lpi/viewExtern?id=12286), 5. Sess)
