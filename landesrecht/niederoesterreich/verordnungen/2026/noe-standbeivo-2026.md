# NÖ Standortbeiträgeverordnung 2026 (NÖ StandbeiVO 2026)

NÖ Standortbeiträgeverordnung 2026 (NÖ StandbeiVO 2026)

StF: LGBl. Nr. 50/2026

## Präambel/Promulgationsklausel

Die NÖ Landesregierung hat am 23. September 2026 aufgrund des § 66a Abs. 5 des NÖ Krankenanstaltengesetzes, LGBl. 9440 in der Fassung LGBl. Nr. 104/2025, verordnet:

## § 1

Die Verteilung der Beitragsleistungen der Gemeinden, in deren Gemeindegebiet sich ein fondsfinanzierter Standort einer NÖ Fondskrankenanstalt befindet, der nicht nur in Form einer dislozierten Tagesklinik oder Wochenklinik betrieben wird, wird ab dem Jahr 2026 wie folgt festgelegt:

| Gemeindename | Verteilungsverhältnis |
|---|---|
| Allentsteig | 0,26% |
| Amstetten | 6,75% |
| Baden | 5,02% |
| Eggenburg | 0,46% |
| Gmünd | 1,14% |
| Grimmenstein | 0,63% |
| Hainburg an der Donau | 1,10% |
| Hinterbrühl | 0,43% |
| Hollabrunn | 1,97% |
| Horn | 2,86% |
| Klosterneuburg | 3,71% |
| Korneuburg | 2,54% |
| Krems an der Donau | 5,92% |
| Lilienfeld | 0,84% |
| Melk | 1,17% |
| Mistelbach an der Zaya | 5,04% |
| Mödling | 3,97% |
| Neunkirchen | 2,52% |
| Scheibbs | 1,12% |
| St. Pölten | 28,31% |
| Stockerau | 2,26% |
| Tulln | 3,45% |
| Waidhofen an der Thaya | 1,26% |

| Zwettl | 2,21% |

## § 2

Diese Verordnung tritt am 1. Jänner 2026 in Kraft.
